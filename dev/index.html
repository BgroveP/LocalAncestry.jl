LocalAncestry.jl: Local Ancestry Inference Using Genome Regions With Variable Lengths

This Julia package provides an accurate, fast, and accessible means of inferring local ancestries. The package is mainly set apart from existing local ancestry software by being a region-based local ancestry inference tool that allows for regions of varying sizes across the chromosome.

Installation

The package is publicly available through the Julia Ecosystem:

using Pkg
Pkg.add("LocalAncestry")

Required inputs

  1. A Variant Call Format file with phased genotypes for reference individuals.
  2. A Variant Call Format file with phased genotypes for target individuals.
  3. A delimited file with ancestries of reference individuals (one ancestry per individual).

Public API

The user of this package only need to run one function to estimate local ancestries:

LocalAncestry.evaluate — Method
evaluate(predla, truela)

Compare predicted local ancestries to true local ancestries per locus.

predla is a DataFrame on the format returned by localancestry and truela is a DataFrame with the true local ancestries on the same format.

Returns a DataFrame with the columns locus (the basepair position), ncorrect (the number of haplotypes predicted correctly at the locus), and pcorrect (ncorrect divided by the number of haplotypes).

LocalAncestry.localancestry — Method
localancestry(referencepath, targetpath, ancestrypath;
              omitpath="", chromosome="", threshold=0.66, maf=0.0001,
              totcm=100.0, maxblockfraction=0.1, printlevel="standard")

Estimate local ancestries for the target individuals.

Reads phased reference and target genotypes in Variant Call Format, builds a library of haplotype blocks from the reference individuals grouped by their global ancestries, and infers local ancestries for the target individuals using a hidden Markov model.

Arguments

  • referencepath::AbstractString: path to the reference VCF file.
  • targetpath::AbstractString: path to the target VCF file.
  • ancestrypath::String: path to a delimited file with the global ancestries of the reference individuals. Must contain the columns individual and population.
  • omitpath::String="": path to a delimited file that denotes the haplotypes to exclude from the reference panel. Must contain the columns individual and haplotype.
  • chromosome::Union{Int,AbstractString}="": the focal chromosome. Defaults to the first chromosome encountered in the reference VCF file.
  • threshold::Float64=0.66: stopping criterion for building genome regions based on the informativeness for assignment statistic.
  • maf::Float64=0.0001: lower limit for the across-population minor allele frequency for a locus to be included in the analysis.
  • totcm::Float64=100.0: genetic length of the focal chromosome in centiMorgans, used for the state-transition probabilities of the hidden Markov model.
  • maxblockfraction::Float64=0.1: upper limit for the length of a genome region, given as a fraction of the number of loci on the focal chromosome. Must be in the interval (0, 1].
  • printlevel::String="standard": either "standard" or "debug", where "debug" prints additional host information.

Returns

  • x::DataFrame: a DataFrame with the columns individual (String), chromosome (String), haplotype (Int), basepairs (UnitRange), and ancestry (String).

LocalAncestry.read_rfmix — Method
read_rfmix(file::String, loci)

Read the local ancestry output from RFMix and convert it to the output format of localancestry.

file is the path to the RFMix output file and loci is a DataFrame with the locus information such as returned by QGIO.loci.

Returns a DataFrame with the columns individual, chromosome, haplotype, basepairs, and ancestry.

LocalAncestry.write_flare — Method
write_flare(la, hapfile::String, outfile::String)

Write predicted local ancestries to a phased Variant Call Format file with ancestry annotations that can be read by FLARE.

la is a DataFrame on the format returned by localancestry, hapfile is the path to the phased VCF file with the target haplotypes, and outfile is the path to the output file.

Returns nothing and writes the output to outfile.
